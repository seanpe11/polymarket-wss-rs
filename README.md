This client is designed to provide rust bindings and wrappers for the types provided by the Polymarket WSS endpoints, please refer to the types provided in:

`src/types/UserChannel.rs` maps to the types defined in the Polymarket docs for the [User Channel](https://docs.polymarket.com/developers/CLOB/websocket/user-channel) (requires auth)
`src/types/MarketChannel.rs` - maps to the types defined in the Polymarket docs for the [Market Channel](https://docs.polymarket.com/developers/CLOB/websocket/market-channel)
